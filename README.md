# OCRheading



\##Description

Supernote plugin for text lasso OCR to heading promotion.



\##Installation

Download the latest built version by clicking Releases and downloading the .snlpg file, or
clone the repository to build the code yourself.

Sync the plugin to your MyStyle folder for now. I may submit for making it an official plugin that can be installed via InkHub later.



\##Instructions

The plugin has a settings menu for selecting font size and heading style. You use the plugin by lassoing handwritten text, then on the context menu selecting "Text OCR Heading".
